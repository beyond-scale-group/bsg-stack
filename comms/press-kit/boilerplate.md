# About Beyond Scale Group

Beyond Scale Group (BSG) is a software holding company that acquires and
operates software businesses forever. Unlike private equity, BSG never
flips — every acquisition joins the portfolio permanently.

**bsg-stack** is BSG's shared technical foundation: reusable CI/CD
workflows, dependency management presets, and an autonomous AI agent
system that maintains code quality across 50+ software companies.

The agent system uses Claude Code to run eight specialized agents that
audit, implement fixes, and peer-review each other's work — shifting
human effort from mechanical maintenance to strategic direction.

Founded: 2024
Headquarters: Paris, France
Portfolio: 50+ software companies
Stack: GitHub Actions, Renovate, Claude Code
