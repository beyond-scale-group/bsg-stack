# Campaign Brief Generation

How to auto-generate a campaign brief stub from a shipped-but-
unmarketed release.

## Scope

A brief is a **starting point**, not a finished artifact. The script
populates a template with facts from the release (tag, date, title,
milestone body) and leaves placeholders for the human to complete:
angle, audience, key message, assets.

## Output location

```
marketing/briefs/YYYY-MM-DD-<tag>-<slug>.md
```

- `tag` is the release tag without the leading `v`
  (`v2.4.0` → `2.4.0`).
- `slug` is a kebab-case truncation of the release title.

## Template

```markdown
---
release: v2.4.0
releasedAt: 2026-04-18
status: draft
---

# Campaign Brief — v2.4.0 Webhook Retry

## What shipped
Automatic webhook retry with exponential backoff. See release notes
for full details.

## Why it matters
_(Fill in: what does this unlock for the customer? What painful
thing goes away?)_

## Audience
_(Fill in: which persona, which segment, which use case?)_

## Key message
_(Fill in: one-sentence value prop.)_

## Assets needed
- [ ] Blog post
- [ ] Changelog entry
- [ ] Landing-page update
- [ ] Social post(s)

## Timeline
Target: within 2 weeks of release.

---

*Auto-generated by @marketing on 2026-04-20. Human review required
before publishing.*
```

## How to run

```bash
# Generate briefs for all unmarketed releases
bash scripts/brief.sh

# Re-generate from an existing snapshot
bash scripts/brief.sh --snapshot /tmp/*.json
```

## Output schema

```json
{
  "generated": [
    { "release": "v2.4.0", "path": "marketing/briefs/2026-04-18-2.4.0-webhook-retry.md" }
  ],
  "existingBriefs": [
    { "release": "v2.3.0", "path": "marketing/briefs/2026-04-10-2.3.0-oauth.md",
      "age": 10, "status": "draft" }
  ],
  "staleBriefs": [
    { "release": "v2.2.0", "path": "...", "age": 31, "status": "draft" }
  ]
}
```

## How to interpret

- **`generated[]`** — the script just created new brief stubs.
  Surface each in the report; the human reviews.
- **`staleBriefs[]` non-empty** → silence-breaker. A brief older
  than 14 days still in `status: draft` means the campaign probably
  won't happen and blocks alignment detection.

## What NOT to do

- Don't complete the brief's placeholders. The agent drafts
  structure, not copy.
- Don't auto-promote a draft brief to `published`. Only a human
  can decide a brief is ready.
- Don't regenerate a brief that already exists. The script
  deduplicates on release tag.
