## Tooling Notes (tech-report skill defects found this tick)

Running `generate-report.sh` as-shipped **failed outright** (exit 2) on this
machine. Four real defects in `claude-skills/skills/tech-report/scripts/`
were isolated and worked around locally (not committed — no code fix was
authorized for this tick) to produce the data above:

1. **`quality.sh` crashes on the common case.** `grep -cE ... "$f" || echo 0`
   double-fires: `grep -c` already prints `0` to stdout on a zero-match file
   but exits 1, so `|| echo 0` appends a second `"0"` line. The resulting
   two-line `$functions` value breaks `(( functions > MAX_FUNCTIONS ))`
   with an arithmetic syntax error on *every* file with zero matched
   functions — i.e. most files, most runs.
2. **`quality.sh` circular-import detection is not portable.** The awk
   block builds a nested associative array (`fwd[$1][$2]`), a GNU-awk-only
   extension. On any awk without it (macOS's default `awk`, Debian's
   `mawk`) this is a syntax error, `CIRCULAR_JSON` ends up malformed, and
   the final `jq -n --argjson circular ...` aborts the whole script with
   `invalid JSON text passed to --argjson` — this is what turned into the
   top-level exit 2.
3. **`collect.sh`'s TODO/FIXME/HACK grep is self-polluting.** It scans
   `*.md` for `(TODO|FIXME|HACK)[:(]`  without excluding
   `tech/reports/*` (its own output directory). Every report's
   `**Summary:** ... TODO: N, FIXME: N, HACK: N` line matches
   `TODO:`, so each report seeds a false-positive debt marker the *next*
   report counts — a purely self-referential, ever-growing "debt" number
   that has nothing to do with the codebase (confirmed: 12/12 matches this
   run were report-summary lines, not code).
4. **`collect.sh`'s `ADR_DIR` candidate list doesn't know about `.bsg/adr`**
   (ADR-001, this repo's own canonical convention), so the ADR section
   always reports "no ADR directory found" even though 3 ADRs exist.
5. **`debt.sh`'s previous-score comparison is unwired.** It reads
   `.previous.debtScore` from the snapshot, but `collect.sh` never
   populates a `.previous` field from git history, so
   `previousDebtScore`/`debtScoreDelta` are always `null` — the "debt
   score regression > 10%" silence-breaker can never fire as built.
6. **`collect.sh`'s `repoRoot` leaks the worktree path.** In a
   `/tick-all`-style git-worktree checkout, `git rev-parse --show-toplevel`
   returns the worktree directory, so the report's `**Repository:**` field
   has been showing `agent-<hash>` instead of `bsg-stack` in every prior
   report (confirmed across the `tech/reports/` history) — corrected by
   hand in this file's header.

None of these are eligible for this tick's audit-to-issue self-filing
(only stale-TODO and oversized-file findings match `auto-implements`), and
opening remediation issues is an externally-visible action that needs
confirmation first per operating principle 6 — flagging here for a human
to decide whether to file them.
