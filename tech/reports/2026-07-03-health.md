## Tooling Notes (tech-report skill defects fixed this tick)

Running `generate-report.sh` as-shipped failed outright (exit 2) again
today — the same defects yesterday's tick (2026-07-02) documented but
left unfixed were still present. Unlike yesterday, this tick **fixed and
shipped** them (PR #693, `needs-human-review`, not self-merged — see
"Merge discipline" below):

1. **`quality.sh` double-echo on the zero-match case.** `grep -cE ... ||
   echo 0` appends a second `"0"` line whenever `grep -c` finds zero
   matches (it already prints `0` and exits 1), breaking
   `(( functions > MAX_FUNCTIONS ))` on most files. Fixed: capture with
   `|| true`, default via `${n:-0}`.
2. **`quality.sh` circular-import detection was gawk-only.** The awk
   block built a nested `fwd[$1][$2]` array — a GNU-awk extension BSD/macOS
   `awk` rejects with a syntax error, silently corrupting `CIRCULAR_JSON`
   via the same double-echo pattern (this time via `pipefail` treating a
   failing awk stage as a pipe failure even though the trailing `jq`
   succeeded). Fixed: portable concatenated `"from\tto"` key, and the
   pipeline result is now validated with `jq -e .` instead of `|| echo`.
3. **`collect.sh` never checked `.bsg/adr`.** ADR detection only looked at
   legacy `adr/` / `docs/adr/` / `architecture/` paths, so this repo's own
   ADR-001 convention was invisible to its own tech-lead audit. Fixed:
   `.bsg/adr` checked first.
4. **`generate-report.sh` leaked the worktree path.** `basename
   $REPO_ROOT` reports the git-worktree directory name
   (`agent-<hash>`) instead of the real repo name under worktree-isolated
   ticks. Fixed: derive from the `origin` remote URL, falling back to
   `basename` only when there's no remote.
5. **`collect.sh`'s TODO scan self-counted its own reports.** The
   `(TODO|FIXME|HACK)[:(]` grep included `*.md` without excluding
   `tech/reports/*`, so every report's own `"TODO: N, FIXME: 0, HACK: 0"`
   summary line matched as a debt marker for the next day's scan. All 17
   markers counted going into this tick were self-counts; real debt is 0.
   Fixed: `tech/reports/*` and `.bsg/reports/tech/*` excluded via git
   pathspec.
