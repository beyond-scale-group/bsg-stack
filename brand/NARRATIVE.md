# Brand narrative — beyond-scale-group/bsg-stack

Voice guidelines, key messages, and positioning for the storytelling
agent to audit public-facing assets against.

## Voice

- **Tone:** Direct, technical, confident. No marketing fluff.
- **Register:** Senior engineer talking to senior engineers.
- **Sentence length target:** 15-20 words average.
- **Passive voice:** Avoid. Active voice is clearer.
- **Jargon:** Use domain terms freely (CI/CD, tick, worktree, LLM).
  Avoid corporate buzzwords (synergy, leverage, paradigm).

## Key messages

1. **One repo, one stack, zero drift.** Every BSG company inherits the
   same CI/CD, the same agent catalog, the same conventions.
2. **Agents audit, implement, and review — humans set direction.**
   The autonomy pipeline handles mechanical work; humans own
   architecture, strategy, and scope.
3. **Safety by design.** Scope contracts, circuit-breakers, peer review,
   and `needs-human-review` on every PR. Autonomy doesn't mean
   unattended.
4. **Scripts before LLM.** Deterministic bash + jq does the counting;
   the LLM narrates. Numbers are never invented.

## Positioning

BSG Stack is infrastructure for a forever-hold portfolio. Not a
framework, not a platform — a shared foundation that makes 50
software companies feel like one engineering org.

The autonomous agent system is the next layer: AI that maintains code
quality, security, SEO, and brand consistency across the portfolio
without burning human attention on mechanical work.

## Anti-patterns (storytelling agent should flag these)

- Marketing language in technical docs ("revolutionary", "game-changing")
- Passive constructions that hide agency ("it was decided", "errors were found")
- Unsupported claims ("the fastest", "the most secure")
- Missing attribution (agent-generated content without disclosure)
